# Extension Development

1. Run `npm install`.
2. Press `F5` to open an Extension Development Host.
3. Open an HTML, JSX, or TSX file containing `<img>` elements.
4. Hover over an image with an empty or missing `alt` attribute, or run **AI Image Alt Text: Fill Missing Alt Text in File** from the Command Palette.
5. On first generation, enter your Ollama server URL and an installed vision model name.

Run `npm test` to compile, lint, and execute the extension tests.
